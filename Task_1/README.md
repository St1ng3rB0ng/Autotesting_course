### **How to SET UP & RUN**
1. Clone project to your machine: ```git clone https://github.com/St1ng3rB0ng/Autotesting_course```
2. Ensure to have installed **JDK 17+** && **Gradle 9.2.0**
3. Run build command  
   on windows powershell:  
   ```./gradlew clean build```or  
   ```./gradlew build``` it will be the same for first run
4. To run tests specifically you can run:  
   ```./gradlew test```or  
   ```./gradlew clean test``` result will be the same for both for the first run
